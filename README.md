## 지원자서류 /지원자 API 명세

**지원자서류**

지원자는 서류를 기수마다 제출 할 수 있습니다.

- 서류 지원 정보
    
    지원자는 이름, 지원기수, 학년, 지원파트, 실력, 열정, 휴대폰 번호, 서류 제출 시간을 가지고 있다.
    
    - 이름은 한글 2글자 이상, 10글자 이하여야 한다.
    - 지원 기수는 해당 지원자가 지원한 기수를 나타내는 1 이상의 정수값이다.
    - 나이는 22살 이상 30살 이하여야 한다.
    - 파트는 기획, 디자이너, 프론트엔드, 백엔드 가 있다.
    - 실력은 해당 동아리원의 실력을 나타내는 0 이상 10 이하의 정수값이다.
    - 열정은 해당 동아리원의 열정을 나타내는 0 이상 10 이하의 정수값이다.
    - 휴대폰 번호는 010으로 시작하는 11자리 문자열이다(예시: 01012345678)
    - 서류 제출 시간은 yyyy-MM-dd hh:mm 형태로 표현한다(예시: 2025-02-28 23:30)
    
    다음과 같은 Post 요청을 통해 지원 서류를 등록한다.
    
    ```sql
    {
        "name": "임준서",
        "period": 11,
        "age": 24,
        "part": "백엔드",
        "ability": 8,
        "passion": 9,
        "phoneNumber": "01012345678",
        "applicationTime": "2025-02-28 23:30"
    }
    ```
    

한 번 등록한 서류는 수정, 삭제할 수 없습니다.

서류를 ID를 이용해 조회할 수 있습니다

- 서류 세부 조회 정보
    - 지원자의 이름
    - 지원 기수
    - 나이
    - 지원 파트
    - 실력
    - 열정
    - 핸드폰번호
    - 지원시간
    
- 서류 리스트 조회 정보
    - 지원자 이름
    - 지원기수
    - 지원파트
    - 좋아요수
- 서류 리스트 필터링 기준
    - 필터링 기준 1: 지원기수별로 10건씩 조회.
    - 필터링 기준 2: 좋아요 수가 높은 순서대로 10건의 서류를 조회.
    - 필터링 기준 3: 지원기수와 좋아요 수를 함께 고려해 10건씩 조회.
    
    **API 예시**: (단순한 예시입니다)
    
    ```sql
    {
        "filterBy": "likes", // "likes", "gisu", "gisu+likes" 선택 가능
        "page": 1,           // 첫 페이지부터 조회
        "pageSize": 10       // 한 페이지에 최대 10건
    }
    ```
    

**지원자**

코테이토에 지원하면 지원자로 등록됩니다

재지원했을시 동일한 지원자ID로 식별합니다(핸드폰번호가 같으면 동일한 지원자로 취급)

지원자의 모든 정보는 수정가능합니다.

지원자 정보 삭제는 불가능합니다.

지원자 정보를 ID를 이용해 조회할 수 있습니다.

- 지원자 정보 조회 정보
    - 지원자 이름
    - 나이
    - 연락처
    
    **API 예시**: (단순한 예시입니다)
    
    ```sql
    {
        "name": "임준서",
        "age": 25,
        "phoneNumber": "01012345678"
    }
    ```
    

## 운영진 API 명세

운영진의 모든 정보는 수정 가능합니다.

운영진 정보 삭제는 불가능합니다.

운영진 정보를 ID를 이용해 조회할 수 있습니다

- 운영진 조회 정보
    - 운영진 이름
    - 나이
    - 연락처
    - 운영진 역할(파트장/기획팀장/홍보팀장/부회장/회장/교육팀장)
    
    **API 예시**: (단순한 예시입니다)
    
    ```sql
    {
        "name": "정찬민",
        "age": 30,
        "phoneNumber": "01098765432",
        "role": "partjang"
    }
    
    ```
    

## 지원자 서류 좋아요 API 명세

- 지원자의 서류에 운영진은 ”좋아요“를 할 수 있습니다.
- 어느 운영진이 좋아요를 눌렀는지 알 수 있어야 합니다.
- 실제 프로젝트의 경우 권한 처리를 해야 하겠지만, 구현의 편의를 위해 권한 처리 없이 진행합니다.
- 지원 서류의 id를 받아서 좋아요 처리를 합니다.
